# PicalexHQ

**High Quality. Every Pixel.**

PicalexHQ is a browser-based photo optimizer for social media. Pick a photo, choose a platform, refine it and download a high-quality result. Everything runs locally in your browser.

🔒 Local processing — your photo is never uploaded.

## Features

- Presets: Instagram Story / Reels, Instagram Portrait, Instagram Square, TikTok, Facebook Portrait, Original
- Fill Frame (cover) and Fit Image (contain) crop modes, with drag-to-reposition
- Filters: Natural, Clean, Vivid, HDR, Cinematic, Warm, Cool, Black & White (with strength control)
- Brightness, Contrast, Saturation, Sharpening with live preview
- Draggable Before / After comparison
- Export as JPG, WEBP or PNG in Standard, High or Ultra quality
- Multi-step high-quality resampling and large-image protection for low-memory phones

## Privacy

No server, no database, no analytics, no external requests. Images are decoded and processed with the Canvas API on your device and are never sent anywhere.

## Files

- `index.html` – page structure
- `style.css` – interface
- `script.js` – image engine and UI

Deployed with PicalexHQ GitHub Builder.
